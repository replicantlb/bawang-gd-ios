# iPhone 版操作手册

## 操作

- 虚拟手柄统一处理方向与 A/B 等按键。触点以起手区域确定归属，相反方向以后按者优先；离开按键、打开独占弹窗、失焦和切后台会释放动作。原按键布局设置保留。
- 自选技能可按场景、攻守城及文系战场用途筛选，支持名称与效果搜索、条件说明和最多 12 套常用配置。载入配置会检查栏位、专属、性别与重复技能。
- 修改器的“清空本栏”表示无技能，“恢复默认”表示移除覆盖、恢复原版。确认选择后须在武将页保存，再通过游戏存档保留。离开未保存的技能草稿会提示。
- 大战场和白刃战的“战况”入口可查看规则、可见武将的持续效果、原引擎提供的禁用原因与冷却，以及最近战报。查看期间暂停，关闭后恢复原状态。
- 新弹窗按可用区域布局，避让安全区域与软键盘，正文可滚动。

## 技能分类和评级

修改器与自建武将共用技能选择器。场景按钮直接显示“全部、内政、战场、白刃战、单挑、攻城、守城、其他”，还可按文系、武系、主动、锁定、诱发、光环、主将、君主、专属、限定、道术、仙系筛选，并与名称／效果搜索和 S～D 评级筛选组合使用。

评级按原版技能说明、成本、触发条件与合理组合价值逐项评估，分别评价内政、战场、白刃战、单挑。S 表示核心极强，A 强且实用，B 正常有用或有明确组合价值，C 条件窄／代价高／收益低，D 明显负面或极低收益。评级是参考判断，不是实测胜率，也不会改变游戏数值。

当前覆盖全部 1106 个可见技能，其中原条目“新毒逝待做”依据不足，以 `?` 表示待评；其余均有 S～D 场景评级及理由。原版部分“大战场”是宽泛登记标签，武圣、无双等按实际白刃／单挑用途归类。跨场景技能分别评分，不将其他场景的能力不足折算进本场景评级。

选择器、武将技能窗口、技能资料列表及详情、战况等标准技能文字位置会显示小角标。角标独立于原按钮文字，不参与选择或保存。富文本技能名使用小字号标记，详情可查看按场景的评价理由。自定义绘图、无技能名称的图标等未使用标准文字控件的位置不自动加标。

## 技能说明面板

修改器和自建武将的技能选择采用同一左右布局：左侧分类、搜索和候选列表，右侧固定保留技能说明。两个区域独立滚动，说明不再随整页滚动被挤出屏幕。顶部栏位单排显示，底部确认和取消保持可见。软键盘缩小可用高度时，暂时收起栏位与分类，继续保留搜索、列表和说明。

## 双面技能、技能默认与装备检查

修改器的技能说明区可直接选择阳面或阴面，两面的技能分别编辑、一起确认，不会改变武将的当前形态。“恢复”只处理正在编辑的那一面。确认选择后，仍须在武将页保存，并通过游戏存档保留本局修改。

修改历史武将时，可勾选“另存新局默认”（双面武将为“两面另存新局默认”）。在武将页保存后，该武将的完整技能配置会用于以后新开游戏；读取旧存档和当前游戏的场景切换不会重新套用。默认保存原始技能配置，不把本局“八阵＊”的事件觉醒进度带入新局；明确自选“八阵”则按选择保存。原版武将的性别与专属限制仍会检查。自建武将沿用原有创建配置，不写入历史武将默认补丁。

菜单 → 其他 → 存档与补丁 → 技能默认，可查看、导出默认配置或移除某名武将的默认。移除和替换前会自动备份；这些操作不改变本局及其他旧存档。默认文件为 `sgz/mod/patches/skills.json`，完整备份也会包含它。

修改器和自建武将的技能说明下方新增装备与技能检查；修改器使用武将页待保存的装备做预览。战况 → 武将技能也会显示当前已解锁技能的联动提示。检查覆盖已核实的原版规则，例如龙魂与青龙刀、玄阵与精盾、无双与无前、连弩、藤甲骑象、巨象与铁骑、学习折扣、将印、吴子兵法及四轮车。提示区分作用对象、条件与覆盖关系，不修改实际游戏规则；未提示冲突也不表示所有组合都已穷尽检查。

## 试炼场与俘虏管理

菜单 → 其他 → 战斗试炼场。请先回到单机内政大地图的选城界面，再开始试炼。可分别选择攻守双方的武将、阴阳面、等级、兵力、技能和四件装备，支持大战场、白刃野战、城门、太守府及单挑。双方沿用当前战役中的基础属性，必须选择不同武将；技能仍检查专属、性别与重复限制。

试炼中由玩家控制攻方、AI 控制守方。点“退出试炼”或完成胜败结算后返回原战役；正式战役的武将、装备、经验、时间与存档不会带回试炼结果。试炼内不开放普通菜单与新局默认补丁保存。若游戏在试炼中意外关闭，下次启动会询问是否恢复到开始试炼前的战役。

菜单 → 其他 → 全势力俘虏。在自己的内政回合，可集中查看本方各城的俘虏，搜索姓名或字，按关押城、原势力筛选，并按忠诚、武力、智力、政治、统率、等级排序。详情显示基础属性及关押位置。“定位关押城”会返回原大地图并移动选城光标，处置仍通过原监狱完成；正在执行内政命令时，请先返回选城界面再定位。

## 单挑、阵型与俘虏列表

单挑普通攻击与舍命一击显示最终参与命中判定的概率，包含原版的保底和动态补正。只调整显示，命中、伤害、暴击、反伤及随机判定规则保持原样。此显示补正仅用于未修改的原版 2.560 脚本；其他模组沿用自身实现。

白刃战选择阵型时，缩略图与展开预览按当前实际部队显示兵种及位置，并列出兵种数量；藤甲、象兵等变化以实际单位为准。不参与布阵的固定单位单独列出。点选阵型可以预览，按 A 才会确认实际布阵。

“全势力俘虏”关闭或定位关押城后，再次打开会保留搜索、关押城、原势力、排序方向及选中武将，并自动滚动到选中行。俘虏释放、转移或消失后，按最新名单恢复有效条件。这些状态仅在当前运行的同一战役和玩家内保留；读档、新开局或切换玩家会清空。

## 键盘收起

iPhone 键盘上方新增“收起键盘”，中文、数字及多行编辑均可使用。点击输入框外部后，待手指松开再收起；点击结果或其他按钮仍执行原动作，切到另一个输入框则继续输入。单行输入可按回车完成，多行文本仍按回车换行。关闭输入页面或切到后台时会清理焦点，避免键盘继续占据横屏区域。

## 君主性格

在单机内政大地图打开菜单 → 其他 → 君主性格，可查看各存续势力现任君主的主副性格、来源、偏好及已记录的前任君主。人物预设覆盖当前启用剧本的全部29位开局君主，并补充常见继承人和重要武将，共60人；这是面向游戏的人物形象预设。其他武将及自建君主自动生成兜底性格，在本局首次使用或存档时固定保存。原版武将的兜底参考原始属性，不随升级和装备变动；生成不消耗战斗随机数。

性格参与 AI 的内政行动、外交偏好、前线及出征留守、选城排序。主性格影响更大，兵粮不足时会调整行动。已选的合法战略目标可延续三个月，局势明显变化、失去合法性或换君主时重新评估。继位使用新君本人的性格，既有盟约、外交关系和战争状态继续保留。此版本不调整白刃战和单挑的临战决策，也不限制玩家手动指挥。

可在页面手动选择现任君主的主副性格，点“保存本局”；“恢复默认”恢复该武将的人物预设或已固定的自动性格。手动选择优先于默认，并跟随武将本人。页面提供即时说明，关闭未保存草稿时会提示；这些设置仍须通过游戏存档保留，不影响其他存档和以后新局。“启用 AI 性格”关闭后恢复原版战略决策，已保存的个人设置仍保留。其他 MOD 或不匹配的原版脚本保留自身 AI。

## 存档与补丁

入口为菜单 → 其他 → 存档与补丁。存档、武将属性补丁和完整备份均可导入或导出。导入单个 `.sav` 前选择目标存档点；导入完整备份按清单恢复，不删除清单外的存档。

在 iPhone 的“文件”App → 我的 iPhone → 霸王的大陆GD 2.560 中，将待导入文件放入 `imports`；导出文件从 `exports` 取出。`backups` 保存每次导入前的备份，可从游戏内“恢复备份”恢复。完整备份包含已有 `.sav`、武将属性补丁、技能默认补丁和技能收藏。

导入前会检查格式、版本、属性范围及备份校验值，并展示内容。原文件先备份，再暂存和替换；普通写入失败会回滚，中断的导入在下次初始化时按恢复记录处理。导入存档不会自动切换当前进度，须通过读取存档进入；属性补丁仅影响新开游戏。
